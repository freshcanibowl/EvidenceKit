# Open EvidenceKit Lite NLI Demo Implementation Plan

Goal: Execute a pinned open-weight NLI model locally and expose a single-claim review UI.
Architecture: Retain the old deterministic CLI as a legacy mode. Add a separate validated Lite contract, offline-only NLI adapter and Gradio UI. Invalid references and time mismatch stop inference. Conflicting model relations require human review.
Tech stack: Python, Transformers, PyTorch CPU, Gradio.
Spec: HF26 Week 3 frozen requirements PDF, reviewed 2026-10-24.

## Constraints
One English claim, 1–5 synthetic evidence records, unique IDs, source type, observed_at; no private code or production changes. Model scores are not calibrated truth probabilities. No silent fallback and no auto-download on review. Publish no unmeasured accuracy or time-savings claims.

- [x] Test and implement validation, relation aggregation and failure behavior in lite.py.
- [x] Pin and download DeBERTa model explicitly; run actual offline inference via nli.py.
- [x] Build local Gradio UI in demo.py; exercise UI through client API.

## Review focus
Unknown IDs must prevent model calls; oversized texts must not silently truncate; partial temporal coverage cannot establish a multi-day claim; conflicting evidence must not become supported; missing model must error, never use fabricated output.
